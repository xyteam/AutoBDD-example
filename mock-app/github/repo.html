WebdriverIO + Cucumber Boilerplate

This project shows you how easy it is to get started with WebdriverIO and Cucumber. It uses the popular wdio-cucumber-framework adapter and demonstrates checking the GitHub website against the scenarios written in Gherkin feature files.

  • Start writing features with Cucumber
  • Run the demo against this local mock of the GitHub site
  • Extend with your own steps and page objects
